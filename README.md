A travel poster for **VELMARA**, a place that isn't there: twin crystal
spires rising out of a sunset sea, the sun sinking between them and its
light scattered across the water. The place's name is set large across the
top of the poster.

Entry for the make.fun bounty [the-poster-for-a-place-that-i-2-20261121-0539](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

## Run

`main.py` (Python 3.13, standard library only) writes the poster to
`/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`):

```sh
python3 main.py
```

The output is a 1024×1024 PNG, deterministically byte-identical on every run.

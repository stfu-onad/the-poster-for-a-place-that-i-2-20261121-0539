A travel poster for **Veldoria**, a place that does not exist: twin crystal
spires rising from a calm sea at sunset, a lone sailboat, and a pine headland
in the foreground. The name VELDORIA is set in large letters across the top,
leading the eye down to the spires and the sun on the horizon.

## Run

```sh
python3 main.py
```

The program writes `entry.png` (1024×1024, 88,446 bytes) to `/output`, or to
the directory named by `MAKEFUN_OUTPUT_DIR` when that is set. It is fully
deterministic and needs no network: the poster bytes are embedded in
`main.py`.
